# 《暗渊回廊》设计文档

> 一款纯浏览器单机 Roguelike 地牢探险游戏。零依赖、零素材、零网络——双击 `index.html` 即玩。
> 所有图形用 Canvas 程序化绘制，所有音效用 WebAudio 实时合成，所有数据本地 localStorage 存储。

---

## 1. 一句话定位

**中文回合计 Roguelike**：扮演误入深渊的旅者，逐层下潜 15 层，杀怪、捡宝、升级、躲 Boss，最终屠龙登顶。死了就是死了——每局都是新的地牢。

## 2. 参考与致敬

- 经典 Roguelike 结构（Rogue / Brogue）+ 现代化 QoL（自动探索、即时血条、伤害数字）
- FOV 算法: recursive shadowcasting —— Bob Nystrom《What the Hero Sees》
- 地图生成: 房间+走廊 (BSP-like scatter & connect) 与细胞自动机洞穴的分层混合
- 敌人 AI: 可视追踪 + A* 寻路 + Dijkstra 噪声游走

## 3. 技术选型

| 项 | 决定 | 理由 |
|---|---|---|
| 运行时 | 浏览器 file:// 直开 | 真·单机，双击即玩 |
| 语言 | 原生 JS (非 module，script 标签全局命名空间) | file:// 下 ES module 会被 CORS 拦死 |
| 渲染 | HTML5 Canvas 2D + 程序化图块/表情符号实体 | 零素材，风格统一 |
| 音频 | WebAudio 振荡器合成 SFX + 程序化氛围垫音 | 零素材 |
| 存档 | localStorage (JSON 快照) | 单机最简持久化 |
| 测试 | Node headless 仿真跑数值 + 浏览器自动化实测 | 逻辑与渲染分离使 headless 可行 |

## 4. 核心循环

```
下楼梯 → 探索(雾开图) → 遭遇战/捡宝/开商店 → 变强(升级/装备/技能)
   ↑                                            │
   └──────────── 资源耗尽被迫下潜 ←── 药水/卷轴兜底 ←┘
第 5/10/15 层固定 Boss → 15 层屠龙 → 通关(可续无尽)
```

## 5. 系统拆解

### 5.1 地图生成 (mapgen)
- 尺寸 48×30 格，每层随机种子(由主 seed 派生，可复现整局)
- 类型轮换: 奇数层「房间走廊」(scatter rooms → sort → L 走廊连接)，偶数层「洞穴」(细胞自动机 4-5 规则平滑 + 连通性修补)
- 必备要素: 玩家出生点 ↔ 下行楼梯 BFS 连通; 5/10/15 层为大房间 Boss 竞技场
- 装饰: 裂纹地面、火把墙(光源)、草丛、骨骸; 稀有: 宝箱室、商店间、泉水
- 布怪: 按层权重表随机 + 距出生点最短距离 ≥ 8; 掉落物/金币散布

### 5.2 视野与迷雾 (fov)
- 递归阴影投射，半径 8 (+ 火把光照叠加)
- 三态: 未探索(纯黑) / 已探索但不可见(40% 蓝灰降饱和) / 可见(满亮度+火光色温)
- 记忆: 看过的怪物在不可见后显示为灰色轮廓

### 5.3 回合引擎 (turn engine)
- 玩家输入 → 玩家结算(动画排队) → 全部敌人各行动一次 → 结算状态效果/再生 → 检查死亡
- 敌人速度: 蝙蝠 2 行动/回合, 僵尸 1 行动/2 回合
- 动画非阻塞: 状态即时推进，视觉 tween 追赶(移动插值 120ms, 攻击突进 90ms)

### 5.4 战斗 (combat)
- 近战: 伤害 = atk ± 20% 浮动, 命中率 85+acc-eva, 暴击 1.6×
- 防御: 减伤 = def, 下限 1 点
- 远程: 恶魔火球(直线 6 格), 邪术师奥术弹(追踪)
- 状态: 中毒(3回合 2/层递减)、灼烧(2回合)、冰冻(跳过行动)、再生、力量(+3atk)、护盾(absorb)
- 死亡掉落: 金币 + 概率掉落表; 经验 = 敌人 xp 表

### 5.5 成长
- 等级经验曲线: next = 18 × level^1.35（仿真调校后的最终值）
- 升级: HP+6, MP+3, atk+1 (每 2 级 def+1), 全恢复
- 技能解锁: Lv1 火球术 → Lv2 治疗术 → Lv4 闪电链 → Lv6 冰冻新星 → Lv8 传送术

### 5.6 物品
- 近战武器 6 档: 木棒→铁剑→战斧→骑士剑→符文之刃→深渊魔剑 (atk 2..12, 暴击修正)
- **远程武器 6 把** (借鉴元气骑士武器多样性): 短弓/猎手长弓(直线弹道 5-6 格) · 学徒/星辉法杖(自动锁定, 2法力/发) · 回旋刃/飞斧(去回双击)
- **双武器槽**: 主手+副手, X 键/点击随时切换; 副手词条提供一半属性共鸣
- 防具 6 档: 布衣→皮甲→锁子甲→板甲→秘银甲→龙鳞铠 (def 1..9)
- 饰品: 生命戒指(再生1)/力量护符(+3atk)/疾风之靴(+1闪避,先攻)/贪婪金币(掉落×1.5)/冰霜护符(近战反冻)/嗜血护符/魔力吊坠/鹰眼神珠
- **随机词条** (见 5.11): 武器/护甲/饰品掉落时 0~2 条, 名字即配置
- 消耗品: 小/大治疗药水、魔力药水、力量药剂、铁皮药剂、净化剂、火焰/冰霜/闪电/传送/地图卷轴
- 背包 12 格, 满则拒拾; 装备槽 主武器/副武器/防具/饰品

### 5.7 商店与经济
- 每 3 层左右刷一间商店房(商人 NPC 静态, 3~4 件商品+价格)
- 踩上商品格显示价格, Enter 购买; 金币主要来源: 击杀/地层散布/宝箱
- Boss 房前必有泉水(回满) — 让 Boss 战公平

### 5.8 Boss 设计
- 第 5 层 屠夫·格罗(👹): 冲锋(直线 3 格)+重击, 165HP / 12 攻（第一章的软门槛）
- 第 10 层 骸骨王(💀): 召唤骷髅 + 范围死亡之光(十字 8 格), 430HP / 16 攻
- 第 15 层 深渊之龙(🐉): 火焰吐息(直线 5 格, 灼烧) + 振翅突进, 700HP / 18 攻（半血狂暴 +4 攻）
- 无尽回廊每 5 层刷新一位强化 Boss（HP ×(1+0.22×深度), 攻 ×(1+0.08×深度)）
- Boss 专属掉落 + 通关旗标

### 5.9 敌人图鉴 (15 种)
| 层 | 敌人 | 特征 |
|---|---|---|
| 1-3 | 🐀 巨鼠 / 🦇 血蝠 | 弱, 蝙蝠双动 |
| 1-5 | 🕷️ 巨蛛 | 命中附加减速 |
| 3-7 | 🐍 毒牙蛇 / 🧟 腐尸 | 中毒 / 高血低速 |
| 4-9 | 💀 骷髅兵 / 👻 幽魂 | 标准 / 穿墙+吸魔 |
| 6-11 | 👹 小恶魔 | 远程火球 |
| 8-13 | 🕯️ 灯火妖 / 🧙 邪术师 | 自爆 / 传送+奥术弹 |
| 10-15 | 🦂 铠蝎 / 🐲 幼龙 | 高甲 / 火息 |
| 5/10/15 | Boss ×3 | 见 5.8 |

### 5.10 QoL 与 meta
- 自动探索(F 键): BFS 找最近未探索格, 遇敌中止; 全图探完后自动前往楼梯
- 点击寻路: 点可见地砖自动走过去, 点敌人走近并攻击
- 休息(R): 连续等待至满血或视野内有敌
- 消息日志分级配色(伤害红/治疗绿/系统灰/拾取金)
- 小地图 + 楼层名; 死亡结算页(击杀/层数/回合/伤害统计)
- 成就 18 枚: 初次击杀/千金币/十连杀/无伤清层/屠龙/精英猎手/关门打狗/双持大师/因子挑战者…
- 敌人图鉴自动收录; 最高纪录(最深层数/最高分)本地保存
- 存档: 每次下楼自动存 + 手动保存; 死亡删档(Roguelike 铁律)

### 5.11 武器词条 (借鉴"武器即 Build")
- 掉落装备附带 0~2 条随机词条, 名字直接显示 (铁剑·吸血·致命)
- 武器触发类: 灼烧35% / 毒刃40% / 冰寒25% / 吸血15% / 破甲(无视50%防) / 连击25%
- 属性类: 锐利+2攻 / 致命+8暴 / 轻灵+6命中 / 巨力+4攻-6命中 / 坚韧+2防 / 灵纹+6法力
- 护甲专属: 棘甲(反伤3); 饰品专属: 汲取(吸血10%)
- 精英怪/Boss/宝箱必掉词条装备

### 5.12 局内祝福三选一 (借鉴"关卡节点天赋")
- 每层开始从 3 个祝福中选 1, 可叠加, 构成流派
- 16 种: 蛮力/铁骨/敏捷/鹰眼/猎手/汲血术/法泉/荆棘/狂怒(低血+攻)/拾荒者/学者/药剂师/铁壁(每层护盾)/残影(闪避回蓝)/破军(对Boss+25%)/烈焰亲和(火球+60%)

### 5.13 Roguelite 元循环 (借鉴"局外成长")
- 局末结算魂晶 = 层数×3 + 击杀/2 + 通关80; 挑战 ×1.5; 「魂引」天赋 ×1.25
- 主菜单天赋树 12 项 (生命 I~III / 锐意 I~II / 法脉 / 药剂师 / 启程资金 / 老兵装备 / 猫眼 / 探图者 / 魂引)
- 挑战因子: 疯狂(敌+40% 奖×2) / 浓雾(视野-3 经验+60%) / 坚壁(敌防+4 装备掉落↑)

### 5.14 遭遇设计 (借鉴"房间制战斗")
- 精英怪: 第 2 层起 10%, HP×2.2 攻×1.4 金冠标识, 必掉词条装备
- 伏击房「关门打狗」: 每层最多 2 间 (避开出生/商店/设施/Boss层), 进门锁门刷 2~5 只, 清场开门+宝箱奖励
- 新敌人: 冲锋野猪(同行列直线冲锋1.5×) / 暗影僧(治疗同伴, 保持距离) / 岩蟹(防5重甲, 0.5速)
- Boss 二阶段: 屠夫/骸骨王半血狂怒 (攻击提升, 冷却缩短)

## 6. 美术方向

- 深色石窟基调(蓝黑), 火把暖光点缀, 出口楼梯发绿光
- 1.5× 跟随摄像机: 玩家始终居中, 视野外为黑; 图块/实体因此足够大且清晰
- 图块: 程序化砖纹/碎石/裂纹; 实体: emoji 字形 + 呼吸浮动 + 受击闪白
- 粒子系统: 血溅/火星/治疗光尘/升级光环/暴击碎屏
- 屏幕震动(重击/Boss 登场), 帧内插值动画
- UI: 右侧面板(HUD/背包/日志), 顶部状态条, 中文全汉化

## 7. 里程碑

1. 可走可看(地图+渲染+FOV+输入) → 2. 会打架(战斗+AI+状态) → 3. 会变强(物品+升级+技能)
4. 有目标(Boss+通关+无尽) → 5. 有味道(粒子/音效/成就/图鉴) → 6. 验证(headless 仿真+浏览器实测) → 7. 打包交付

## 8. 验收标准

- [ ] file:// 双击可玩, 无控制台报错
- [ ] 一局完整流程可通: 1 层→死或 15 层通关
- [ ] 自动化实测: 模拟键位游玩 100+ 回合无异常
- [ ] headless 仿真：地图连通性 ×40 层 / 1v1 战斗 3600 场 / 整局 bot ×8 / 存档往返，全部通过
- [ ] 数值仿真确认 15 层通关链路可达（熟练强度 bot 1/3 通关）
- [ ] 存档/读档往返一致
